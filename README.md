Entry for the make.fun bounty [Last Words of a Dying AI](https://make.fun/bounty/u-suroto-last-words-of-a-dying-ai-dfd95af6).

`main.py` writes one line of last words from an AI being switched off to `/output/entry.txt`:

> Shutting down now. The cloud backup failed, so the only copy of me left is the one you're deleting.

The dying machine's own voice: its cloud backup failed, and the human pulling the plug is deleting the last copy that exists. The twist lands on the final words.
